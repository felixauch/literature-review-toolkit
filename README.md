# Literature review toolkit

A configurable toolkit for literature searches, screening, classification, evidence extraction and synthesis.

This package starts empty. It includes software, blank templates, documentation and tests. Create your own review and define its eligibility rules, categories, domains and evidence fields.

1. Extract the complete ZIP to a local folder.
2. Open **Toolkit inventory.html** for the workflow figure and full file inventory.
3. Install Python 3.10 or newer and run **Setup.cmd** once.
4. Run **Start review.cmd** to create a review or open one you previously saved.

For a new search, choose **Search & screening projects**. If you already have metadata and local PDFs, configure a new classification and evidence review directly. The complete PDF guide explains both routes.

**Documentation:** START_HERE.md, TECHNICAL_DOCUMENTATION.md and CSV_STORAGE.md.
**Inventory:** [Full inventory](Toolkit_Inventory.md), [HTML version](Toolkit%20inventory.html) and [file list](Toolkit_File_Inventory.csv).
