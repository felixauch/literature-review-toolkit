# Start here

Extract the ZIP completely. On Windows, install Python 3.10 or newer, run **Setup.cmd** once, then run **Start review.cmd**. The setup page opens in your browser.

- To begin with database exports, expand **Search & screening projects** and create a review.
- To begin with metadata and PDFs, enter the files and define categories, domains and evidence fields.
- To resume your own saved work, choose **Open saved review**.

The package contains no saved projects, papers, decisions, evidence caches or subject-specific category definitions. The files under `projects/_template/` and the blank review-settings template are starting points for your configuration.

Open **Toolkit inventory.html** for the workflow and file inventory. The complete PDF guide covers the full process; **CSV_STORAGE.md** explains saved records and backups.
