# Combined review module

Use **Start review.cmd** in the package root. Configure the review on its HTML setup page; choose **Open saved review** to return to saved work. The complete illustrated guide is in the package root.

For command-line use from the root: `python toolkit.py workspace`, or `python toolkit.py workspace --run "C:/Research/my-run"`.

USER_GUIDE.md and STRUCTURED_REVIEW.md describe the review fields and saved states. Source PDFs and the input CSV remain separate from the editable run; back up all of them.
