# Combined classification, evidence and synthesis module

This module is included in the literature review toolkit. Start from **Start review.cmd** in the package root; the configuration is entered in HTML. Read the root README and complete PDF guide for the full search-to-synthesis workflow.

`start.py --run RUN` resumes a prepared review. `project_setup.py` retains optional command-line configuration and validation for scripted workflows. `setup_server.py` and `setup_ui/` implement browser setup. No LLM inference or model service is used.
