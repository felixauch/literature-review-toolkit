Review & synthesis toolkit

Continue with classification, evidence and synthesis

The full toolkit contains both this search/screening module and the current combined review workspace.

  1. Save title/abstract and full-text decisions here.
  2. Collect and verify the PDFs. Include decisions must be yours; draft suggestions are not carried over as decisions.
  3. Open Start review.cmd and open Search & screening projects, select your saved project and click Use included papers.
  4. Select this project. Configure your own categories, domains, fields and answer choices.
  5. Choose a new run folder. The handoff reports any missing PDFs or decisions.
  6. The combined interface opens for independent category decisions, evidence extraction and synthesis maps.

Transfer uses explicit human full-text Include decisions. Pending decisions stay in the screening project and are reported at handoff.

For exact commands and screenshots, open the complete PDF guide in the ZIP.
