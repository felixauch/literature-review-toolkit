# Runtime connection audit - 28 September 2026

The toolkit was developed with assistance from GPT-6 Astra. This guide and the accompanying documentation were generated by GPT-6 Astra.

The release was inspected for model SDK imports, inference endpoints, process launches and network code. No runtime call to a local or external LLM was found. This does not mean that all scripts are offline.

## Local processing

Database-file parsing, deduplication, rule suggestions, PDF imports, PDF text/section extraction, classification forms and evidence/synthesis operate locally. The optional title/abstract SVM is a local statistical classifier, not an LLM. The default requirements do not install it. Neither the category matcher nor the extraction form calls it.

Browser setup communicates with a loopback service. It uses a per-process token and Host/Origin checks, starts the packaged Python tools without shell interpolation, and stores settings only in a new path. Extraction has a Python audit hook blocking sockets and child processes after parser initialisation; this is not an operating-system sandbox.

## Optional external connections

- Setup.cmd/pip downloads declared Python dependencies.
- Crossref and OpenAlex provide bibliographic metadata and citation links for chosen stages and DOI lookups.
- Unpaywall/OpenAlex locate open-access PDFs; downloads contact the returned source hosts.
- Opening DOI/publisher links is a browser action.
- OPENALEX_API_KEY is optional and is attached only to the exact HTTPS api.openalex.org host. The package contains no credentials.

No paper text is sent to an inference service by this release. Provider queries may include bibliographic identifiers or search terms. Source access permissions and provider terms remain separate from this code audit; this is not a blanket legal certification.
